AI 视频一键配乐与自动人声避让

Video-to-Music 生成背景音乐 → Scribe 精确定位讲话 → 按停顿合并 → FFmpeg 平滑压低音乐。云计算接口预留，当前本地执行。

本地样例无需 API Key
讲话区间可编辑
重复混音不重复扣费
原始视频音轨保留

1 导入视频

建议 MP4、60 秒以内。当前 Demo 限制文件 100 MB、视频最长 600 秒。可以直接加载内置样例，验证完整离线处理。

2 生成背景音乐

使用 ElevenLabs Video-to-Music，默认不生成额外 SFX，以免影响客户原始音效。没有 API Key 可上传已有音乐继续走完流程。

3 识别人声区间

Scribe v2 返回词级时间戳。根据相邻词的停顿时间将多个词合为一段讲话，不按单字调音量。你可以手工覆盖合并后的结果。
