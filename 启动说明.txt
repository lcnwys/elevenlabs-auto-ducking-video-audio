ElevenLabs Auto Ducking Demo — 本地启动
====================================

环境：Python 3.9+、FFmpeg 和 ffprobe（须在 PATH 上），macOS / Linux / Windows 皆可。

1. 解压 ZIP，终端进入 elevenlabs-auto-ducking-demo 目录。
如果使用 macOS：确认 FFmpeg 已安装（brew install ffmpeg），双击「启动_Mac.command」即可建立 Python 虚拟环境并启动本地服务。

手动安装：
2. 安装依赖：
   python -m pip install -r requirements.txt
3. 可选：在终端设置 ElevenLabs API Key（只在调用真实 API 时需要）：
   macOS / Linux: export ELEVENLABS_API_KEY='你的密钥'
   PowerShell:   $env:ELEVENLABS_API_KEY='你的密钥'
   不要写入前端 HTML；密钥也不要上传到代码仓库。
4. 运行服务：
   python -m uvicorn app:app --host 127.0.0.1 --port 8765
5. 打开浏览器：http://127.0.0.1:8765
6. 点击「使用内置样例」→ 调整音量参数 →「开始 FFmpeg 混音」→ 试听/下载。

真实使用：上传视频 → 调用 Video-to-Music 或上传已有音乐 → 调用 Scribe 或手动设置讲话区间 → FFmpeg 混音。

可选测试：python -m pytest -q
可选本地 FC 执行器示例：python fc_worker.py fc_job.example.json

注意：
- 本 Demo 是本地验证，不带账号登录、任务队列、文件过期清理和防滥用机制，不应直接暴露到公网。
- 不会自动发起付费 API 请求，只有点击相应按钮才调用 ElevenLabs。
- 音乐与人声不保证听感完美；对旧的已混在原视频中的音乐不会执行分离或衰减。
- 正式 ElevenLabs API 通路需要有有效 API Key 和 Music/Scribe 调用权限后进行在线验证。
- FFmpeg 许可证与生成内容的商用授权请在项目正式上线前核对。

【v0.2 真实 API 校验新增】
1. 运行“启动_Mac.command”可使用网页 Demo；本地离线样例无需 API Key。
2. 打开终端进入项目目录，先执行：source .venv/bin/activate
3. 仅检查 Key：python scripts/live_smoke.py （隐藏输入，默认只发 GET /v1/user）
4. 明确同意消耗额度后：python scripts/live_smoke.py --paid
   此步骤对内置样例截取 8 秒：最多调用一次 Scribe v2 + 一次 Video-to-Music，失败不重试。
5. 成功结果位于 runtime/live-smoke/；运行期间不会把 Key 保存到源码或输出文件。
6. 阿里云 CLI（Mac）：brew install aliyun-cli；认证建议 OAuth：
   aliyun configure --mode OAuth --profile fc-ducking-dev
   aliyun sts get-caller-identity --profile fc-ducking-dev
   完整函数计算方案见 FC_架构与验收方案.html；此版本不会创建云端函数。
注意：FC 韩国首尔当前不支持自定义容器与异步任务组合，先测试日本东京或新加坡。
