处理步骤

1. 导入视频

浏览器上传 MP4/MOV/WebM/MKV，或加载内置样例。FastAPI 为任务生成随机 ID，保存到 runtime/{job_id}，用 ffprobe 读取时长、视频流和音频流。限制单文件 100 MB、视频不超过 600 秒。

2. 准备配乐

可上传已有音乐，也可调用 ElevenLabs POST /v1/music/video-to-music。当前设定模型 music_v2_5、add_sfx=false、separate_tracks=false；输出先写入临时文件，确认有音轨后替换正式配乐。

3. 获得讲话时间戳

有原视频音轨时，可调用 ElevenLabs POST /v1/speech-to-text，参数使用 scribe_v2 与 word 级时间戳。也可以跳过识别，在页面逐行输入起止秒数。

4. 合并讲话区间

core.py 忽略非 word 条目、校验时间范围，并按可调静音间隔合并相邻词。手动区间也会排序、合并，并限制在视频时长内。

5. 生成平滑音量包络

每个讲话区间两侧加入可调前置/后置余量；用攻击和释放时间形成平滑增益曲线，写成 1 kHz 单声道 PCM WAV 控制信号。默认讲话时衰减 16 dB。

6. 混音并交付

FFmpeg 将新配乐按默认 -12 dB 混入，应用包络在讲话期间降低音乐，并与原视频音轨混合。视频优先不重编码；容器不兼容时回退到 H.264。页面提供结果试听与 MP4 下载。

接口与能力清单

接口 / 模块用途关键参数或数据
POST /api/video上传与探测视频，创建任务multipart 文件；返回 job_id、duration、has_audio、has_video
POST /api/sample加载本地演示素材不发起外部 API 请求
POST /api/music/{job}生成视频配乐描述、是否参考原音频；服务端调用 Video-to-Music
POST /api/music-upload/{job}上传现成配乐MP3/WAV/M4A/AAC/FLAC/OGG
POST /api/transcribe/{job}获取讲话词级时间戳Scribe v2；视频须含音轨
GET /api/timeline/{job}读取字幕词条和合并时间段静音合并阈值 gap
POST /api/render/{job}本地音频避让与输出衰减 dB、常态音量、前后余量、attack/release、可选手动区间
GET /api/file/{job}/result试听或下载结果返回任务目录中的 output.mp4

当前状态与边界

已实现：本机 FastAPI 页面、上传/样例、ElevenLabs 音乐与转写调用、手动讲话区间、FFmpeg 混音和结果下载。

尚未实现：客户在网页单独填写 Key；Vercel 公网部署。

当前 ElevenLabs Key 从服务器环境变量 ELEVENLABS_API_KEY 读取。任务文件写在本机 runtime/，不是云端持久存储。当前项目目录没有 Git 仓库；Vercel CLI 未安装。公开部署前需先确定客户 Key 的传输与保留策略，以及上传和输出文件在云端的存储方式。

主要源码：static/index.html、app.py、elevenlabs_client.py、core.py；依赖：FastAPI、Uvicorn、httpx、python-multipart、FFmpeg/ffprobe。
